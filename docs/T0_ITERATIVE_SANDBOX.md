## Private tester

Its prompt, tools, filesystem view and logs carry no tester instructions, checks, private artifacts, seeds, results or remediation hints. The worker sees only its normal task and public gate feedback. Run the tester from a separate read-only view of campaign inputs, with a private output root outside both agents' workspaces. Enforce access at the runner boundary. If tester review uses the same Qwen model, issue a new request after resetting the slot. The tester's model review can flag semantic leakage for adjudication and the controller computes the final verdict from recorded checks.

## Early stopping during discovery

The production canvas already stops oversize edits and rewrite attempts mid-stream, and ends attempts after repeated identical refusals or compiler errors. Keep those controls fixed. A partial append, a new compiler diagnostic, or a compiling revision with failing tests can still lead to a valid repair.

A candidate discovery rule is to stop before starting a sixth model call if the first five calls completed and the canvas has yet to produce a compiling revision. Count calls after the harness evaluates their edits, and use a trusted harness event for the compilation milestone. A staged edit, timeout, or model claim does not establish compilation. This rule caps time spent on a hypothesis and cannot establish that the candidate would fail at full budget.

A retrospective check on the five corrected cutoff-hint trials and Generation 3 observed:

| Stop if nothing compiles after | Corrected hint passes preserved | Generation 3 model calls skipped | Time between the cutoff and final reply in Generation 3 |
| --- | ---: | ---: | ---: |
| Four calls | 1 of 2 | 3 | 155 s |
| Five calls | 2 of 2 | 2 | 134 s |

The later successful hint trial first compiled on call five and passed on call seven. Generation 3 ended with a compile failure after seven calls. These six observations justify shadowing the five-call rule on more full-budget trials. In shadow mode, log when it would have stopped, then measure any valid late passes and time saved. If enabled later, label stopped runs DISCOVERY STOPPED, record the rule and supporting artifact, and keep the result outside proof denominators. Full-budget proof keeps the same gate and budgets for both arms.

## Tool-use probe

[t0_tools.py](../validation/tiers/t0_tools.py) asks whether the canvas worker uses the forms it has, picks the right one and writes it well formed. Each reply is judged in three tiers, stopping at the first failure: **T1 invoked** (a transaction in a form the arm offers, not prose or an invented form), **T2 selected** (the forms the task calls for: SYMBOL for a whole function, SEARCH/REPLACE for a few lines, READ before editing a folded function, AFTER to finish a cut-off file), and **T3 well-formed** (valid headers and terminators, a path in the view, a SEARCH text that occurs exactly once, an AFTER position and READ range inside the file, FILE never replacing a real file). The `need` arm adds `FIND TOOL`, and a task that no offered form can do should get that request naming the missing capability. Every request is kept in `tool-needs.jsonl` with its verdict (named, false-need, wrong-need, substitute, unframed or malformed); a request written without the `===` framing is `unframed`, for harness review. Nothing adds or runs a tool from it. Automating that step with a frontier review is not built: the frontier tier stays off until the owner enables it.

```powershell
python -B validation/tiers/t0_tools.py list
python -B validation/tiers/t0_tools.py selftest                       # no model: 26 scripted controls
cd validation/tiers; python -B -m unittest test_t0_tools              # the scorer's edge cases
python -B validation/tiers/t0_tools.py run --out NEW_DIR --model qwen35 --arm need --samples 3   # opt-in: calls the engine
```

The live run uses its own tool block, not the production canvas prompt (`src/canvas_agent.cpp`), so its rates describe the forms rather than the shipped prompt. It defaults to the shared server on port 8092: run it only with the owner's go-ahead and the session that uses that engine (see [STATUS.md](STATUS.md) section 6).
